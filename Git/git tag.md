## Git Tag

[[Git]]에서 **특정 커밋에 고정된 이름**을 붙이는 기능입니다.

일반적으로 다음과 같은 용도로 사용합니다.

- 배포 버전을 표시할 때
- 테스트 기준 버전을 고정할 때
- 특정 시점의 코드를 다시 재현할 때
- 사용자에게 동일한 코드 버전을 제공할 때
- 릴리스 이력을 관리할 때

예를 들어 `main` 브랜치가 변경되더라도, 태그가 가리키는 커밋은 자동으로 이동하지 않습니다.

## 현재 커밋에 태그 생성하기

현재 체크아웃된 브랜치의 최신 커밋인 `HEAD`에 태그를 생성하려면 다음 명령을 사용합니다.

```bash
git tag -a <태그 이름> -m "메시지"
```

## 특정 커밋에 태그 생성하기

현재 다른 브랜치에서 작업 중이어도 특정 커밋 해시를 직접 지정하여 태그를 생성할 수 있습니다.

```bash
git tag -a <태그 이름> <커밋 SHA> -m "메시지"
```

## 태그 목록 확인

현재 로컬 저장소에 존재하는 모든 태그를 확인합니다.

```bash
git tag
```

특정 패턴의 태그만 확인하려면 다음 명령을 사용합니다.

```bash
git tag -l "local-test-*"
```

## 태그 상세 정보 확인하기

태그가 가리키는 커밋과 태그 메시지를 확인하려면 다음 명령을 사용합니다.

```bash
git show <태그 이름>
```

## 태그를 원격 저장소에 Push하기

>[!WARNING]
>`git tag` 명령으로 생성한 태그는 먼저 **로컬 저장소에만 존재합니다.**
>사용자가 해당 태그를 사용할 수 있도록 하려면 반드시 원격 저장소에 Push해야 합니다.

```bash
git push origin <태그 이름>
```

모든 로컬 태그를 한 번에 Push할 수도 있습니다.

```bash
git push origin --tags
```

## 원격에 태그가 올라갔는지 확인

```bash
git ls-remote --tags origin
```
