### 데스티니 2 - IT 및 운영 부서(IT and Operations Department) 핵심 직무 정리

| 직무 명 (Role Name) | 핵심 업무 및 역할 |
| :--- | :--- |
| **IT / Operations Director**<br>*(IT / 운영 디렉터)* | 스튜디오 전체의 IT 인프라, 정보 보안, 장비 예산, 기술 장비 관리 및 사내 네트워크 운영 전략을 총괄하는 최고 책임자입니다. |
| **DevOps / Infrastructure Engineer**<br>*(데브옵스 / 인프라스트럭처 엔지니어)* | **[데스티니 2의 핵심 직무]** 개발팀과 IT 운영의 가교 역할로, 게임 서버 배포 자동화(CI/CD), 클라우드 인프라 관리, 고성능 빌드 서버 환경을 구축합니다. |
| **Information Security Engineer (InfoSec)**<br>*(정보 보안 엔지니어)* | **[데스티니 2의 핵심 직무]** 게임 소스 코드 및 미공개 신규 시즌 정보(IP) 유출 방지, 사내 사이버 공격 및 해킹 방어, 내부 시스템 보안을 책임집니다. |
| **System Administrator (SysAdmin)**<br>*(시스템 관리자)* | 사내 데이터베이스, 사내 클라우드 서버, 개발 협업 툴(지라, 콘플루언스 등), 이메일 및 계정 권한 등의 안정적인 유지 보수와 데이터 백업을 담당합니다. |
| **Network Engineer / Administrator**<br>*(네트워크 엔지니어 / 관리자)* | 2,000명이 넘는 직원의 고속 사내 인터넷망, 원격 근무를 위한 안정적인 VPN, 데이터 센터 간 통신 연결, 내부 방화벽을 관리합니다. |
| **Database Administrator (DBA)**<br>*(데이터베이스 관리자)* | 전 세계 수백만 플레이어의 계정 정보, 인벤토리 아이템, 실시간 접속 로그 등 막대한 용량의 라이브 서비스 데이터를 처리하는 서버 DB를 최적화하고 유지합니다. |
| **IT / Desktop Support Specialist**<br>*(IT / 데스크톱 지원 전문가)* | 개발자들이 업무에 사용하는 고사양 PC/워크스테이션 조립, 소프트웨어 라이선스 지급, 일상적인 하드웨어 및 소프트웨어 장애 해결을 지원합니다. |
| **Studio / Facilities Operations Manager**<br>*(스튜디오 / 시설 운영 매니저)* | 개발자들이 쾌적하게 일할 수 있도록 사옥 물리 보안(출입 통제), 전력 및 서버실 온도 유지, 자산 관리, 재택근무 장비 배송 등 스튜디오 시설 전반을 관리합니다. |
