### 데스티니 2 - 아트 부서(Art Department) 핵심 직무 정리

| 직무 명 (Role Name) | 핵심 업무 및 역할 |
| :--- | :--- |
| **Art Director**<br>*(아트 디렉터)* | 게임 전체의 비주얼 스타일, 색채, 분위기(톤 앤 매너)를 총괄하며, 모든 아트 팀이 일관된 예술적 방향성을 유지하도록 이끄는 최고 책임자입니다. |
| **Concept Artist**<br>*(콘셉트 아티스트)* | 3D로 구현되기 전, 행성 배경, 캐릭터, 방어구, 적(몬스터) 등의 초안과 원화 일러스트를 그려 시각적인 가이드라인을 제공합니다. |
| **3D Character Artist**<br>*(3D 캐릭터 아티스트)* | 플레이어(수호자), NPC, 외계 종족(몰락자, 군체 등)의 고화질 3D 모델링, 스컬프팅(조각), 텍스처 매핑 작업을 담당합니다. |
| **3D Hard Surface / Weapon Artist**<br>*(하드 서피스 / 무기 아티스트)* | 총기, 검, 우주선(점프선), 기계 장치, 방어구 등 금속이나 기계적인 구조물의 3D 모델링과 정교한 디테일 제작을 전문으로 합니다. *(데스티니 2의 핵심 직무)* |
| **3D Environment Artist**<br>*(3D 환경 / 배경 아티스트)* | 지구, 유로파 등 게임 내 광활한 행성의 지형, 자연물, 건축물, 던전 내부 등의 3D 오브젝트를 만들고 배치하여 게임 월드를 구축합니다. |
| **Lighting Artist**<br>*(라이팅 아티스트)* | 빛과 그림자를 이용해 공간의 입체감과 분위기를 살리고, 플레이어의 시선을 유도하며, 조명 최적화 작업을 담당합니다. |
| **VFX Artist / Visual Effects Artist**<br>*(시각 효과 아티스트)* | 수호자의 스킬(태양, 전기, 공허, 시공, 초월 등), 총기 화염, 폭발, 연기, 파티클 효과 등 역동적인 특수 효과를 제작합니다. *(데스티니 2의 핵심 직무)* |
| **Technical Artist (Tech Art)**<br>*(테크니컬 아티스트)* | 아티스트와 프로그래머 사이의 가교 역할로, 그래픽 셰이더 작성, 아트 제작 툴 개발, 그래픽 프레임 최적화 등을 담당합니다. |
| **UI/UX Designer / Interface Artist**<br>*(UI/UX / 인터페이스 아티스트)* | 체력바, 스킬 아이콘, 무기 인벤토리, 메뉴 화면, 지도 등 사용자와 게임을 연결하는 인터페이스 시각 디자인을 담당합니다. |
| **Cinematic / Storyboard Artist**<br>*(시네마틱 / 스토리보드 아티스트)* | 스토리 컷씬이나 트레일러 영상의 카메라 구도, 연출 흐름을 스토리보드로 그리고 영상 비주얼 파이프라인을 구축합니다. |
| **Additional Art / Outsource Lead**<br>*(추가 아트 / 외주 아트 관리)* | 외부 협력사(외주 스튜디오)에서 제작하는 에셋(모델링, 텍스처 등)이 번지의 품질 기준을 충족하도록 검수하고 가이드를 줍니다. |
