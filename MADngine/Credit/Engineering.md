### 데스티니 2 - 엔지니어링 / 프로그래밍 부서(Engineering Department) 핵심 직무 정리

| 직무 명 (Role Name) | 핵심 업무 및 역할 |
| :--- | :--- |
| **Engineering / Technical Director**<br>*(엔지니어링 / 테크니컬 디렉터)* | 게임 기술의 총괄 책임자로, 전체 코딩 아키텍처, 기술적 방향성 및 표준을 수립하고 엔지니어링 팀 전체를 이끄는 리더입니다. |
| **Engine / Core Engineer**<br>*(엔진 / 코어 엔지니어)* | **[데스티니 2의 핵심 직무]** 번지의 자체 기술인 '타이거 엔진'의 핵심 시스템, 메모리 관리, 데이터 로딩, 멀티스레딩 등 최하단 기술(로우레벨)을 개발하고 최적화합니다. |
| **Gameplay Engineer**<br>*(게임플레이 엔지니어)* | **[데스티니 2의 핵심 직무]** 무기 발사, 스킬 구현, 캐릭터 이동, 충돌 감지, 인벤토리 시스템 등 플레이어가 실제로 조작하고 겪는 게임 내 모든 규칙과 액션을 코드로 구현합니다. |
| **Network / Multiplayer Engineer**<br>*(네트워크 / 멀티플레이어 엔지니어)* | **[데스티니 2의 핵심 직무]** 수천 명의 유저가 동시에 접속하는 MMORPG 환경에서 탄속, 피해량 계산, 플레이어 위치 등이 지연(랙)이나 끊김 없이 동기화되도록 сетевой 프로토콜을 개발합니다. |
| **Graphics / Rendering Engineer**<br>*(그래픽스 / 렌더링 엔지니어)* | 빛, 그림자, 특수 효과(VFX), 고해상도 텍스처 등이 화면에 빠르게 그려지도록 렌더링 파이프라인을 구축하고 최신 그래픽 하드웨어(GPU)에 맞춰 프레임을 최적화합니다. |
| **AI / Bot Engineer**<br>*(AI 엔지니어)* | 외계 적 종족들이 길을 찾고(Pathfinding), 지형물을 이용해 엄폐하며, 플레이어를 포위하는 등 똑똑하고 자연스럽게 전투를 펼치도록 인공지능 로직을 구현합니다. |
| **Tools / Pipeline Engineer**<br>*(툴 / 파이프라인 엔지니어)* | 아티스트와 디자이너들이 맵을 만들고 아이템을 쉽게 배치할 수 있도록 사내 에디터, 시각화 도구, 데이터 변환 프로그램 등 개발 보조 소프트웨어를 만듭니다. |
| **Audio Engineer**<br>*(오디오 엔지니어)* | 게임 엔진 내에서 3D 공간 음향, 거리에 따른 소리의 감쇠, 사운드 메모리 최적화 등 기술적인 오디오 재생 시스템과 파이프라인을 개발합니다. |
| **UI / Slate Engineer**<br>*(UI 엔지니어)* | 메뉴 화면, HUD(체력 및 탄약 표시), 장비 창, 지도 등 인터페이스 요소들이 프레임 저하 없이 부드럽게 작동하고 마우스/패드 조작에 즉각 반응하도록 프로그래밍합니다. |
| **Server / Backend Engineer**<br>*(서버 / 백엔드 엔지니어)* | 유저의 계정 정보, 클라우드 저장 데이터, 매치메이킹(전장 매칭), 클랜 시스템, 보안 및 Anti-Cheat(핵 방지) 시스템 등 서버 단의 인프라를 구축하고 관리합니다. |
| **Build / Release Engineer**<br>*(빌드 / 릴리즈 엔지니어)* | 수백 명의 개발자가 작성한 코드와 에셋을 하나로 통합하여 게임을 패키징(빌드)하고, 플레이스테이션, PC, Xbox 등 각 플랫폼에 안정적으로 패치 및 배포하는 자동화 시스템을 관리합니다. |
