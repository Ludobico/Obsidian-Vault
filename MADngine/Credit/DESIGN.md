### 데스티니 2 - 디자인 부서(Design Department) 핵심 직무 정리

| 직무 명 (Role Name) | 핵심 업무 및 역할 |
| :--- | :--- |
| **Design Director / Creative Director**<br>*(디자인 / 크리에이티브 디렉터)* | 게임 플레이의 비전, 핵심 재미 요소, 장기적인 콘텐츠 방향성을 총괄하며 디자인 팀 전체를 이끄는 최고 책임자입니다. |
| **Sandbox Designer**<br>*(샌드박스 디자이너)* | **[데스티니 2의 핵심 직무]** 무기, 방어구, 직업별 스킬, 특성(Perk), 캐릭터 이동 물리 등 플레이어의 조작감과 전투 생태계(밸런스)의 기초 공사를 담당합니다. |
| **Activity / Encounter Designer**<br>*(액티비티 / 인카운터 디자이너)* | **[데스티니 2의 핵심 직무]** 레이드(Raid), 던전, 공격전(Strike) 등에서 보스의 공격 패턴, 특수 파훼 기믹(퍼즐), 몬스터 스폰 타이밍 등 구체적인 전투 상황과 규칙을 설계합니다. |
| **Level / World Designer**<br>*(레벨 / 월드 디자이너)* | 플레이어가 탐험하는 행성과 전투 공간의 3D 구조, 이동 동선, 시야각, 엄폐물 배치 등을 설계하여 탐험의 재미와 전술적 전투 공간을 만듭니다. |
| **Investment / Economy Designer**<br>*(인베스트먼트 / 경제 디자이너)* | **[데스티니 2의 핵심 직무]** 아이템 드롭률, 레벨업 성장 곡선, 재화(미광체, 실버 등)의 소비와 획득, 시즌 패스 보상 등 플레이어가 게임을 지속적으로 플레이할 동기와 경제 시스템을 설계합니다. |
| **Narrative / Quest Designer**<br>*(내러티브 / 퀘스트 디자이너)* | 작가(Writer)들이 쓴 스토리와 세계관을 실제 플레이어가 수행하는 퀘스트 목표, 인게임 이벤트, 대화 트리 등으로 자연스럽게 연결하여 구현합니다. |
| **Multiplayer / PvP Designer**<br>*(멀티플레이어 / PvP 디자이너)* | '시련의 장(Crucible)'이나 '갬빗' 같은 플레이어 간 대전(PvP/PvEvP) 모드의 규칙, 점수 체계, 맵 밸런스, 부활 위치 등을 전문적으로 설계합니다. |
| **AI / Combat Designer**<br>*(AI / 전투 디자이너)* | 몰락자, 기갑단, 군체 등 외계 적 종족들의 인공지능(AI) 행동 패턴, 엄폐 전략, 공격 시도 주기 등 몬스터들의 지능적인 전투 방식을 설계합니다. |
| **Technical Designer**<br>*(테크니컬 디자이너)* | 디자이너와 프로그래머의 가교 역할로, 스크립트 언어를 사용해 복잡한 게임 내 기믹을 직접 프로토타이핑하거나 기획 업무를 돕는 도구(Tool)를 개선합니다. |
| **Live / Seasons Designer**<br>*(라이브 / 시즌 디자이너)* | 게임이 출시된 이후에도 3~4개월 단위로 업데이트되는 시즌별 신규 콘텐츠, 한정 이벤트, 지속적인 밸런스 패치를 기획하고 운영합니다. |
